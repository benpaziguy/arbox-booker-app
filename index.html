Arbox booker

This page talks straight to Arbox from your browser — the same API the gym's own site uses. Nothing goes through any other server. Your password is used once to get a session token and is never stored; the token lives in this tab only and is gone when you close it.

Registration opens 48h before most classes, 72h for Sunday and Monday. A class further out shows Queue: tap it and GitHub Actions claims the seat the second its window opens, days later, with nothing of yours running. Your recurring weekly slots are already handled the same way.

Queue settings

Paste a token once and this phone is set up for good — it is remembered, so this is not a per-visit login. Create one here, set Repository access → Only select repositories → , then Repository permissions → Contents → Read and write. Nothing else is needed.

Why a token at all: something must act at 03:00 when registration opens, and a phone browser is asleep. So this writes the request into schedule.json and GitHub Actions does the booking. The token cannot be baked into this page — the page is served from a public repo, so it would be readable by anyone. Scoped to one repo, the worst a lost phone can do is edit this schedule.
